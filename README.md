## Ce que fait Klipr

- **Analyse une VOD de n'importe quelle durée** : un fichier sur ton PC, un lien Twitch ou un lien YouTube (vidéo ou rediff de live).
- **Repère les moments forts** : tes réactions au micro, les rires, le chat qui s'enflamme (KEKW, Pog, « CLIP »…), l'action à l'écran.
- **Ignore l'intro et la fin du stream** (écran d'attente, musique, motion design).
- **Monte des clips 9:16** : facecam + jeu (dans l'ordre que tu veux), recadré ou fond flou. Tu places toi-même la facecam et la zone du jeu.
- **Sous-titres automatiques animés**, titre en bandeau, accroche, zooms sur les réactions, coupe des blancs.
- **Tout se passe sur ton PC** : aucune vidéo n'est envoyée sur Internet, pas d'abonnement.

## Télécharger

Va dans **[Releases](../../releases)** (colonne de droite) et télécharge :

- `Klipr-Setup.exe` : l'installateur (recommandé)
- `Klipr-portable.zip` : sans installation, dézippe puis lance `Klipr.exe`

> 🚧 Première version bientôt disponible.

**Configuration :** Windows 10 ou 11 (64 bits), 8 Go de RAM conseillés, environ 2 Go d'espace libre. Une carte graphique NVIDIA, AMD ou Intel accélère les exports.

## Installation

1. Lance `Klipr-Setup.exe`.
2. Si Windows affiche **« Windows a protégé votre ordinateur »**, clique sur **Informations complémentaires**, puis **Exécuter quand même**. Le logiciel n'est pas signé numériquement : c'est normal pour un petit développeur indépendant.
3. Au premier export avec sous-titres, Klipr télécharge son modèle de transcription (environ 480 Mo), une seule fois.
